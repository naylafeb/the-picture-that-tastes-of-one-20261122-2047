# The picture that tastes of one ingredient

One bowl of steaming ramen — tonkotsu broth, a jammy soft egg, chashu, nori and green onion, chopsticks lifting a glossy bundle of noodles. One ingredient at the centre: the broth, and the steam you can taste.

The picture was drawn as an original SVG illustration and rendered to `entry.png` (1024×1024) with headless Chromium. `main.ts` copies it to the output path.

## Run

```sh
node main.ts
```

It writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR`).
